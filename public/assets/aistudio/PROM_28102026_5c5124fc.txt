# PROYECTO: SISTEMA WEB PARA EL REGISTRO Y CONTROL DE ACTIVIDADES EN LÍNEAS DE SUBTRANSMISIÓN

## 1. OBJETIVO DEL PROYECTO

Desarrollar un sistema web profesional para el registro, control y supervisión de actividades realizadas en líneas de subtransmisión eléctrica.

El sistema será desarrollado utilizando Visual Studio Code y tendrá como almacenamiento principal archivos de Excel y hojas de cálculo de Google almacenados en Google Drive.

*No utilizar MySQL, MariaDB, XAMPP ni ningún otro servidor de bases de datos.*

Los registros se almacenarán en archivos de Excel y Google Sheets alojados en Google Drive. La aplicación leerá, registrará, modificará y consultará esos archivos mediante las API oficiales de Google.

El sistema debe permitir:
- Gestionar líneas de subtransmisión.
- Gestionar estructuras.
- Administrar usuarios y contratistas.
- Registrar inspecciones de deficiencias.
- Registrar inspecciones termográficas.
- Registrar inspecciones de efecto corona.
- Registrar actividades de poda.
- Registrar actividades de mantenimiento.
- Importar DMS desde archivos Excel.
- Gestionar levantamientos de DMS.
- Realizar inspecciones de verificación y cierre de DMS.
- Almacenar evidencias fotográficas en Google Drive.
- Generar dashboards y reportes.
- Registrar las modificaciones realizadas por cada usuario.
- Mantener los archivos de datos actualizados en Google Drive.

No entregar únicamente un prototipo visual. Desarrollar una aplicación funcional con formularios, validaciones, permisos, lectura y escritura de archivos, auditoría y documentación.

## 2. TECNOLOGÍAS OBLIGATORIAS

Utilizar:
- Visual Studio Code como entorno de desarrollo.
- HTML5 para la estructura de la página.
- CSS3 para el diseño.
- JavaScript para la interacción y lógica del frontend.
- Una arquitectura web compatible con alojamiento estático y funciones de servidor.
- Google Sheets API para consultar y actualizar hojas de cálculo.
- Google Drive API para acceder y administrar archivos autorizados.
- Chart.js para los dashboards.
- Una biblioteca de JavaScript compatible con archivos Excel, como SheetJS, para importar o exportar archivos XLSX cuando sea necesario.
- Google OAuth 2.0 para la autenticación y autorización de acceso a los servicios de Google.
- Google Apps Script o funciones de servidor para las operaciones que requieran acceso seguro a las API.

No utilizar:
- MySQL.
- MariaDB.
- XAMPP.
- phpMyAdmin.
- Tablas de bases de datos SQL.
- Servidores SQL.
- Archivos JSON o localStorage como almacenamiento principal de los registros.

Se permite utilizar archivos temporales, caché y almacenamiento de sesión para el funcionamiento de la interfaz, pero los registros oficiales deberán guardarse en los archivos de Google Drive establecidos por el administrador.

El sistema debe tener una arquitectura clara que separe la interfaz, la lógica de negocio y el acceso a los archivos de Google.

## 5. SINCRONIZACIÓN CON GOOGLE DRIVE

Implementar sincronización entre la página web y los archivos almacenados en Google Drive.

La sincronización debe funcionar en ambos sentidos cuando el formato y las API utilizadas lo permitan.

### Cambios realizados desde la web

Cuando un usuario agregue, edite o desactive un registro:
- Validar la operación en el servidor.
- Actualizar el archivo oficial.
- Registrar la auditoría.
- Actualizar la interfaz.
- Informar si la sincronización fue exitosa.

### Cambios realizados directamente en Google Drive

Cuando un administrador modifique un archivo directamente en Google Drive:
- Detectar los cambios mediante un mecanismo de sincronización.
- Leer las filas modificadas.
- Actualizar la información que utiliza la aplicación.
- Mantener las relaciones entre los registros.
- Registrar el origen y la fecha de la sincronización.
- Identificar los conflictos.

### Automatización

Implementar:
- Sincronización al abrir un módulo cuando corresponda.
- Botón de sincronización manual.
- Sincronización automática periódica.
- Registro de la última sincronización.
- Gestión de errores.
- Reintentos controlados.
- Detección de duplicados.
- Historial de sincronizaciones.

Si se necesita detectar cambios externos, utilizar las notificaciones, activadores o tareas programadas que sean compatibles con el servicio configurado.

No afirmar que la sincronización es instantánea si realmente funciona mediante consultas periódicas.

### Protección contra conflictos

Si dos usuarios modifican el mismo registro:
- Detectar que el archivo o registro ha cambiado.
- Evitar sobrescribir silenciosamente información.
- Registrar el conflicto.
- Mostrar los valores en conflicto a un usuario autorizado.
- Permitir decidir qué modificación conservar.
- Registrar la resolución en el historial.

Utilizar COD_LINEA para relacionar las líneas con las estructuras y actividades, pero no depender exclusivamente de la posición de una fila de Excel, ya que las filas pueden ordenarse o desplazarse.

- PRIORITARIO.

PARA TIPO DE DEFICIENCIAS EN EL MOMENTO DEL REGISTRO SE DESPLIEGA UNA LISTA DESPLEGABLE CONLAS SIGUIENTES OPCIONES PARA LAS DEFICIENCIAS
- Presencia de agujeros en la parte superior de los postes de madera tipo H.
- Postes de madera requieren de instalación de refuerzos metálicos 
- Estructura tipo H presenta fisuras en la parte inferior.
- Dados de concreto que protegen la base de los postes tipo H, se encuentran quebrados
- Se requiere embadurnar estructura de celosía
- Refuerzos metálicos instalados en la parte superior de los postes de madera presentan corrosión.
- Presencia de agujeros en las crucetas de madera. Sellar y reforzar las crucetas con rieles metálicos
- Presencia de agujeros de consideración en las crucetas de madera. Se deben de cambiar las crucetas.
- Refuerzos metálicos instalados en las crucetas de madera presentan corrosión.
- Presencia de agujeros en las riostras de madera tipo X.
- Riostras de madera tipo X presentan agujeros de consideración. Se deben de cambiar.
- Riostras metálicas en postes tipo H presentan corrosión.
- Se recomienda cambiar las varillas de retenidas en las estructuras que cumplen la función de ángulo o tipo vértice
- Se observa cables de retenidas destemplados.
- Se observa presencia de maleza que ha trepado por los cables de las retenidas hasta la parte superior de las estructuras.
- Cables de PAT cortados en la parte superior de los postes y crucetas de madera
- Se observan cables PAT corroídos y/o cortados en la parte inferior de las estructuras de madera. También se observan conexiones que no garantizan un buen funcionamiento del sistema de aterramiento. Se deben de mejorar las conexiones utilizando conectores adecuados.
- Se observa presencia de ramas de platanales cerca de los conductores. Se requiere podar a la brevedad. Nivel de criticidad medio
- Se observan cometas atrapadas en los aisladores de las estructuras.
- Bastidores metálicos instalados sobre las crucetas de madera, se encuentran mal instalados y propensos a caer sobre los conductores de aluminio.
- Se observa recorte de terreno cerca de las bases de las estructuras tipo H.
- Muretes de señalización de riesgo eléctrico se encuentran en mal estado. Presentan fisuras y corrosión.
- Carteles de código de línea y número de estructura, se encuentran borrosos. 
- Falta resanar entrada de los cables de puesta a tierra en las lozas de concreto. Se observa que se ha tenido que picar parte de la loza de concreto para conectar y/o tender los cables de puesta a tierra
- Presencia de basurales cerca de la estructura de madera 
- Carteles de señalizaciones se encuentran amarrados con alambre en la estructura
- Predios no cumplen con DMS e invaden la F.S.
- Estructuras de madera tipo H se ubican dentro de terrenos de sembríos o zonas húmedas

Estados sugeridos:
- Registrada.
- Pendiente de revisión.
- En atención.
- Corregida.
- Pendiente de verificación.
- Cerrada.
- Rechazada para corrección.

La evidencia fotográfica será obligatoria.

El sistema debe exigir una fotografía nueva o un enlace válido a una evidencia autorizada cuando se registre o modifique una actividad que requiera fotografías.
